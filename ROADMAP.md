# Roadmap

This is a proposed roadmap, not a promise of implemented features.

- [x] Offline CLI with safe preview and explicit apply
- [x] Codex (`AGENTS.md`) and Claude Code (`CLAUDE.md`) support
- [x] Non-destructive managed blocks, backup, drift detection, basic tests
- [ ] Better secret detection with configurable local scanners (opt-in)
- [x] Manifest-backed conflict-aware undo of new backups (unreleased development)
- [x] Import existing unmanaged rules and diagnose project health (unreleased development)
- [x] Opt-in Gemini CLI project-rule support (unreleased development)
- [x] GitHub Actions drift-check example (unreleased development)
- [ ] More tested integrations based on actual user needs
- [x] Validate source/wheel package builds in CI (unreleased development)
- [ ] Publish first PyPI package through verified maintainer-controlled release workflow
- [ ] Community issue triage, reproducible bug reports and user feedback

Feedback on real-world cross-agent workflows is more valuable than increasing feature count for its own sake.
